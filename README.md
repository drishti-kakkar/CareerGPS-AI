# CareerGPS AI

AI-powered Career Intelligence Platform

## Live Demo
https://careergps-frontend.vercel.app

## Features
- Resume Analysis
- GitHub Audit  
- Career Roadmap
- Job Finder
- LinkedIn Optimizer
- Interview Prep
- AI Chat Advisor

## Tech Stack
- Frontend: Next.js + Tailwind CSS
- Backend: FastAPI + Python
- AI: Groq + Llama 3.3
- Deployed: Vercel + Render

## Setup

### Backend
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

### Frontend
cd frontend
npm install
npm run dev
